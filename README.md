# 여행말 Yeohaengmal

韓國旅遊韓文單字卡，手機 PWA，可離線使用（旅ことば系列的韓文版）。<https://jeremyl861225.github.io/yeohaengmal/>

- 約 1200 個旅途會用到的單字與常用句（製作中，目前是 30 張樣本）：機場入境、地鐵與交通卡、巴士計程車、住宿、汗蒸幕與澡堂、餐廳、烤肉與炸雞、咖啡廳與點餐機、購物退稅、便利商店、美妝保養、看醫生、醫美與皮膚科、緊急求助、韓服與拍照打卡、追星與演唱會、招牌標示，以及店員與廣播常對旅客說的話。
- 每張字卡：漢字詞上方標漢字、寫法和唸法不同時標實際唸法、羅馬拼音、發音（女聲、男聲交替）、旅途情境例句與中文。
- 依「旅遊實用頻率」排序，分必備、常用、進階三級，級內依主題分課；每課可學習與測驗。
- 測驗八種題型：看韓文選中文、看中文選韓文、看韓文選實際唸法、聽發音選單字、聽發音選中文、聽例句選意思、用音節方塊拼出韓文、聽寫。

## 資料與授權

- 漢字與實際唸法校對、離線字典：國立國語院《[韓國語基礎辭典](https://krdict.korean.go.kr/)》（CC BY-SA 2.0 KR）。
- 羅馬拼音：依韓國文化體育觀光部《國語的羅馬字表記法》自行轉換（反映連音、鼻音化、流音化、顎化，不標緊音化），`tools/pipeline/rr.py`。
- 字型：[Noto Serif KR](https://fonts.google.com/noto/specimen/Noto+Serif+KR)（SIL Open Font License 1.1，授權全文 `fonts/OFL.txt`），依字卡用字裁切。
- 發音：Microsoft 神經語音，以 [edge-tts](https://github.com/rany2/edge-tts) 產生，僅供個人學習。
- 例句與中文解釋由 AI 撰寫並經字典比對；如有錯誤歡迎回報。
- 程式碼與字卡內容 © 2026 jeremyl861225。
